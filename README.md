# Top-Aktien

Eigene App neben dem Ki Aktien Helfer: die besten Aktien und ETFs für die nächsten 3, 7 und 30 Handelstage, mit Gründen, Ausblick, Quellen, Bilanz, Updates nur mit Zustimmung und Muster-Speicher.

- Rechnung, Telegram-Bot und Daten: Wachmann im Repository `timaxGg/638291738` (`bot/signale.mjs`), Ergebnis in `kurse.json` (Zweig `kurse`).
- KI-Recherche: geplante Claude-Aufgabe „Top-Aktien Recherche“ (Anleitung `trading/KI-AUFGABE.md` im Haupt-Repository).
- Diese App liest nur. Einstellungen (Finnhub-Schlüssel, GitHub-Token) kommen aus der Haupt-App, gleiche Adresse timaxgg.github.io.

Keine Anlageberatung.
